# CS-300-Data-Structure-and-Algorithms
A portfolio of C++ projects developed for CS 300: Data Structures and Algorithms at SNHU.

## About This Repository
This repository contains my work from CS 300: Data Structures and Algorithms at Southern New Hampshire University. The projects demonstrate my understanding of data structures, algorithm efficiency, and applying C++ programming concepts to solve problems.

Project One: An analysis of the run-time and memory requirements of different data structures, including vectors, hash tables, and binary search trees.

Project Two: A C++ program designed to read course information from a file, organize the data, and display a list of Computer Science courses in alphanumeric order.

## Reflection
### What was the problem you were solving in the projects for this course?
The main problem I was working to solve was how to efficiently organize, store, and retrieve course information for an academic advising program. In Project One, I compared different data structures to determine which would be most effective for managing course information. In Project Two, I developed a C++ program that reads course information from a file and allows users to view course information in an organized way. Both projects helped me understand how data structures and algorithms work together to solve real-world problems.

### How did you approach the problem? Consider why data structures are important to understand.
I approached these projects by breaking the requirements into smaller steps and evaluating the different ways information could be stored and accessed. I learned that understanding data structures is important because the structure selected can affect a program’s speed, efficiency, and overall performance. Comparing vectors, hash tables, and binary search trees helped me understand why certain structures are better suited for specific tasks. This allowed me to make more informed decisions when designing my program.

### How did you overcome any roadblocks you encountered while going through the activities or project?
One of the biggest challenges I encountered was making sure the program worked correctly while also meeting the project requirements. I had to work through issues involving program logic, reading information from files, and organizing the data correctly. When I encountered problems, I reviewed my code, checked for errors, and tested different parts of the program to identify what needed to be corrected. Working through these challenges helped me become more patient and confident in my troubleshooting abilities.

### How has your work on this project expanded your approach to designing software and developing programs?
These projects helped me realize that software development involves more than just writing code that works. I now understand the importance of planning the structure of a program before beginning development. Evaluating data structures and considering their performance helped me see how design decisions can affect the overall functionality and efficiency of software. Moving forward, I will approach programming problems by considering the requirements, available solutions, and long-term functionality before deciding how to implement them.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
My work in CS 300 has helped me better understand the importance of writing organized and readable code. I have learned to use meaningful variable names, separate tasks into functions, and structure programs in a way that makes them easier to follow. I also understand that writing maintainable code makes it easier to identify errors, update features, and make improvements without having to rewrite the entire program. These are skills I plan to continue developing as I progress through my Computer Science program.
